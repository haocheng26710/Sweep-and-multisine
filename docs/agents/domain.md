# Domain docs

This repository uses a single-context domain-document layout.

Before exploring an area, read the root `CONTEXT.md` when it exists and relevant ADRs under `docs/adr/`. If either is absent, proceed silently. Use terminology defined in `CONTEXT.md`; surface any conflict with an existing ADR instead of silently overriding it.

`CONTEXT.md` and ADRs are created lazily when domain terminology or architectural decisions require them.
