# V2.5-S1 单模块频率标定分析报告

日期：2026-08-24  
状态：真实数据分析完成；S2/S3 尚未分析；未运行分类器；`final_test_read=false`

## 1. 结论先行

V2.5-S1 得到了有效但有明确边界的结果：

1. **设计频率的顺序和局部调谐总体成立。** 八个预定目标从 1200 Hz 到 4500 Hz 的实测局部特征保持严格递增；实测中心相对 CAD 目标的绝对误差中位数为 **2.03%**，最大为 **5.83%**。
2. **四个模块形成了跨两个独立 block 的稳定目标局部特征：HR02、HR03、HR05、HR07。** 其中 HR03 和 HR07 最强；HR02、HR05 较弱但两 block 均超过同时段 P05 局部重复性底线。
3. **尚未形成八个、也尚未形成原定四个彼此正交的“频谱条形码”。** 原定 S3 组合 HR01/HR03/HR05/HR07 中，只有 HR03 和 HR07 的自身目标通道进入本模块八个固定通道效应的前两名；HR01、HR05 的自身通道均排第 8。
4. **因此 S3 的理想四方向结果并非当前最可能结果。** 更合理的预测是：S3 会有诊断价值，可能保留部分强模态，但出现清晰四方向—四频率对角矩阵的概率有限。
5. **仍建议按原计划完成 S2 和 S3。** S2 是同时段直管阵列对照；S3 是区分“共同腔破坏频率码”（方案 3A）与“频率码保留但入口角度选择性不足”（方案 3B）的最小必要实验。现在停在 S1，只能证明单模块调谐，不能回答装置是否适合方向研究。

这不是 H1 确认，也不支持可靠方向分类。它支持的是更具体的工程结论：**V2.5 已把第一代经验几何差异推进到可预定频率顺序的局部调谐，但当前模块响应仍含明显共享频谱骨架，通道专属性不足。**

## 3. 分析方法与边界

- 固定预处理：200–8000 Hz、48 PPo 对数网格、1/12-octave dB smoothing；
- 主频带：200–4000 Hz；次要频带：4000–8000 Hz；
- 每个 block 用三次连续技术重复的中位曲线；
- 每个 HR 与同 block 的 P05 基线相减；
- 每个 CAD 目标只在预先给定的 ±1/6 octave 局部窗中寻找峰/谷，并用窗口边缘线性趋势去除后的局部对比量评估；
- 稳定条件同时要求：两 block 同极性、局部中心一致、两 block 的窗口 RMS 均超过同时段 P05 局部 p95、特征不在搜索边界；
- 曲线异常只 flag，不自动删除；
- 没有用 S1 训练方向分类器，也没有读取 S2、S3 或 final-test。

必须注意：局部搜索窗由 CAD 目标预先给定，所以“找到一个靠近目标的极值”本身不是充分证据。只有跨 block 重现、超过局部重复底线并具有通道专属性，才可解释为可靠编码。

## 4. 数据质量与重复性

同时段 P05 基线在 200–4000 Hz 的六个组内 pairwise RMS 的描述性 p95 为 **0.7635 dB**，低于历史 CONT p95 **0.8793 dB**。P05 两个 block 中位曲线的跨 block RMS 为 **0.5530 dB**。

除 HR08-B01 外，所有条件/block 的最大组内 pairwise RMS 均低于历史 0.8793 dB。HR08-B01 最大值为 **1.2029 dB**；其中 `V25S1-HR08-B01-R01` 到本 block 中位曲线的主频带 RMS 为 **1.0221 dB**，按保守规则被 flag。该曲线没有删除，所有正式表和图继续保留它。HR08 不在原定 S3 四模块中，因此不建议在完成 S2/S3 前专门重测它。

九个条件的跨 block 主频带 RMS 均低于历史 0.8793 dB；最大为 HR04 的 **0.7612 dB**。这说明总体装配/时间漂移受控，但不代表每个目标局部特征都稳定。

## 6. 为什么“频率命中”仍不等于“四个频率码”

八个 HR−P05 代表谱在 800–5000 Hz 的两两 Pearson 相关范围为 **0.501–0.902**，中位数 **0.717**。这比“所有曲线完全相同”更有分化，但仍显示大量共享结构。该相关定义不同于旧 P06 的固定窗口相关，不能直接把两个数值作严格优劣比较。

更直接的通道专属性检查把每个模块都投影到八个预定目标窗：

| 原定 S3 模块 | 自身目标窗在该模块八窗中的效应排名 | 自身窗/本地 p95 | 解释 |
|---|---:|---:|---|
| HR01 | 8 | 0.67 | 1200 Hz 不是 HR01 的主导可测变化 |
| HR03 | 2 | 2.12 | 有较强自身通道，但 3800 Hz 公共窗仍更强 |
| HR05 | 8 | 1.41 | 2700 Hz 可重复，但不是 HR05 的主导变化 |
| HR07 | 1 | 5.71 | 清晰、强且专属性最好 |

原定四模块的六对局部半功率非重叠指标全部大于 1，说明四个选定局部中心在频率轴上相距足够远；但这只说明“目标窗不重叠”，不说明每个模块只激活自己的窗。

尤其值得注意的是，HR01、HR03、HR05、HR07 在约 3800 Hz 的 HR07 窗口都出现很强变化，相对各自 P05 局部 p95 的比值分别约为 **6.76、5.21、6.81、5.71**。这说明 3.8–4.0 kHz 附近含有明显共享模态或共同几何响应。若四个模块同时装入共同中心腔，该公共响应可能掩盖弱通道，而不是自然形成理想的对角响应矩阵。

## 7. 是否继续 S2 与 S3

### S2：应继续

S2 不是重复旧 U4SYM，而是本次 V2.5 活动的同时段 P05 U4 对照。没有 S2，就无法把 S3 的频谱变化与当前密封、当前房间和当前装配状态分开。

### S3：应继续，但定位为诊断实验

继续原定 HR01/HR03/HR05/HR07 配置，完成两个独立 block。理由不是预期它必然成功，而是 24 份 S3 是区分以下两种机制的最小真实证据：

- S1 模态装入 U4 后消失、合并或大漂移：支持共同腔/通道耦合是主要瓶颈，进入 **方案 3A**；
- S1 模态在 U4 中仍可见，但四方向的归一化通道向量相似：支持外部入口角度选择性不足，进入 **方案 3B**；
- S3 有可重复方向差异但 block 泛化或整体增益处理较弱：先进入 **方案 1**，用现有数据做冻结校准和现有模块重组；
- 只有 S3 表明单模块中心在共同腔中仍系统性偏移/重叠时，才进入 **方案 2**。S1 当前中心误差和六对频率间距本身不支持立刻重打调谐模块。

不建议在本轮后根据 S1 两个 block 事后替换原定 S3 模块。HR02 比 HR01 更稳定，但其自身目标窗在八窗中仅排第 6；现有数据并没有给出一个明显更优、四条都专属的替代组合。先完成冻结配置能保留研究可解释性；若失败，再把 S1 作为方案 1/仿真的校准数据，前瞻性冻结下一组合。

## 8. 对 V2.5 结果的预测

当前预测为：**V2.5 很可能比 P06 更清楚地展示“可设计频率顺序和局部共振”，但不太可能在无挡板、共同中心腔、原定四模块配置下直接得到理想的四方向—四通道独立编码。**

这里的“混合结果”仍有论文价值，因为它能够把论文从“几何似乎改变频谱”推进到：

1. CAD 目标到实测中心的定量误差；
2. 哪些通道跨独立装配保留；
3. 频率间距足够但通道专属性仍不足；
4. 最终瓶颈位于内部共同腔还是外部角度门控。

最可能需要的下一层不是立即进入方案 2 重打共振器，而是先由 S3 在 **方案 3A 与 3B** 之间定位。结合旧 P06 完整阵列方向差较弱、且本版暂不使用挡板，方案 3B 是重要风险；但 S1 中已出现明显共享 3.8–4.0 kHz 响应，方案 3A 同样不能排除。
