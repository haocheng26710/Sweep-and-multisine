## 1. 结论先行

项目没有因阴性结果而失去科研价值；FORMAL 对原 U4 四方向确认性目标给出了合格的阴性/受限结论，P04B 和 R256 也真实地限制了当前 COMSOL 模型的资格。问题在于，后续阶段多次把“当前实现或当前模型失败”扩大为“原科学问题已经被承接或无需再回答”。最严重的四项是：

1. TRANS 二状态实体成功被用来推进或替代原四方向目标，而二状态只需要一个对比维度，不能语义等价地回答四状态/连续方向问题；
2. TRANS-4 在 INFO-TOP-0 被标为等待 TOP-4，TOP-4 随后把近独立四状态实体设计留作 future work，却宣布核心论文故事已完整，形成未获明确用户授权的终点替换；
3. INFO-TOP 将“单麦观测能力—编码信息—传感成本—更普遍拓扑”主要收缩为既有 N/S 数据、单个 R256/N 空间锚点和预设 `K(alpha)` 降阶包络；随机/无序或超材料启发对照、连续方向和可信全波拓扑比较未进入合同；
4. TOP-4 以“设计原则”作为核心闭环，但其 H-COUPLING/H-MATCH 只在结构上会随 `alpha` 压缩中心化状态差的 Level C 模型中成立，尚不能替代实体或可信全波机制验证。

这些事件不是说已有结果无效。已有结果应保留为严格分层的真实阴性、有限二状态正结果和 Level C 理论线索；但原四方向与更普遍设计问题仍在 active ledger 中，必须由用户决定恢复、明确降级或正式终止。

## 5. 对八个重点问题的回答

### 5.1 原方向编码目标在哪里被拆解或替代

FORMAL 将问题合规拆为谱形效应、相对重复误差、结构差值、REASM 和 grouped readout。这是计划内分解。FORMAL-5 的阴性结论直接支持“不确认 H1/不支持可靠分类”。SUP 与 V2.5 又合理拆出“单入口谱源”“目标频率调谐”“共同腔破坏”。真正发生替代的是后续叙事把“可测谱差/机制干预/二状态码”当成原方向 readout 的完成路径，而没有继续保持四状态终点为 active。

### 5.2 四方向→谱差→单入口→共享腔→二状态→INFO-TOP

- 四方向到“谱差存在”：有 FORMAL 直接证据，但只能作为受限结论，不能等价替代 readout。
- 单入口签名：有 SUP-1 直接证据，属于机制分解，不是方向证据。
- 共享腔干预：P04T2–T4 有真实有界证据，合理增加科学内容，但只回答控制趋势。
- 二状态 TRANS：有真实正证据，但任务维度降低，不能承接四方向；缺少明确授权其成为新的最终终点。
- INFO-TOP：用户关于观测能力/编码/成本/普遍拓扑的方向被写入合同，但实际实现主要是已有数据和降阶模型。其“核心闭环完成”缺少对未进入合同问题的显式用户决定。

### 5.3 P05–P10 是否过早取消

P04B-N 直接证明当前名义模型不具备完整 U4 预测资格，P04T3 又证明局部实体峰谷定位失配，因此不能按旧合同直接执行 P05–P08/P10；这一点合理。问题是 `BLOCKED_AND_CLOSED_UNDER_CURRENT_CONTRACT` 容易把合同关闭扩展成问题关闭。P04E/F 已恢复了一部分理想化机制干预，但 P07 外场、P08 完整 U4 能量归因、P09C 近独立/星形流形和 P10 同标准鲁棒比较仍未完成。它们应进入恢复账本，而非默认永久取消。

### 5.4 TRANS-2/3/4 关闭映射

`TRANS-2 SUPERSEDED_BY_AS_BUILT_TWO_PORT_DEVICE` 只在实体装置确实实现原冻结几何、验收和科学角色时才成立；当前关闭表没有给出等价映射证据。`TRANS-3 FULFILLED_BY_TRANS1_TWO_PORT_PHYSICAL_PILOT` 对“实体二状态 pilot”可能实质完成，但缺少原 TRANS-3 合同，不能验证是否还承诺跨闭合/完整对照。`TRANS-4 DEFERRED_PENDING_INFO_TOP4` 后，TOP-4 又把四状态近独立实体设计留作 future work；这不是完成，而是问题遗失。

### 5.5 INFO-TOP 是否过早降阶

是，且属于本次最重要的恢复点。TOP-2 使用真实 N/S 谱差加唯一 N 状态保存解构造两个空间包络；TOP-3 用预设 `K(alpha)` 和循环置换的 A/B/D/F 签名构造三类拓扑。这些是有价值的 Level C 分析，但不构成“更普遍拓扑”的充分代表集。随机/无序谐振网络、超材料启发结构、明确共享腔模态物理、连续方向流形和同成本理想反向设计没有进入执行合同。

### 5.6 工具失败是否被当成假设失败

多数阶段处理正确：P00、P03 初试、P04D、TRANS-0/1 retries 都明确写为技术失败且没有声学否定。可疑之处不在单个失败报告，而在阶段关闭时把“当前模型/API/网格不可用”与“无需再回答全波/外场问题”合并。审计要求未来继续使用两套状态：`technical_validity` 与 `scientific_hypothesis`。

### 5.7 指标、阈值、频带、重复和终点变化

- rev-001→rev-002 的 200–4000 Hz、48 PPO、smoothing 与门槛冻结发生在正式 pilot 前，且主问题/主指标未变，合理。
- FORMAL 实际 72/96、AS02 单 block 降低了确认能力；有充分披露，但用户授权证据需补齐。
- V2.5 从跨 block 改成单 campaign、S1 5-of-6 与 S2/S3 3-of-4有明确用户要求，属于授权变更；结论已相应降低。
- P04/TRANS 使用各自 campaign 的重复性底线并有披露，不能回写 FORMAL 门槛。
- 最关键的终点变化不是数值阈值，而是状态数、证据等级和科学终点：四方向 readout→二状态谱差；实体/全波→Level C 原理。

### 5.8 值得恢复与不应恢复

最值得恢复的是：一般编码模型与可证伪稳定秩、随机/启发式多入口对照、同成本反向设计、有限可信全波验证、连续方向/四状态桥接。可选的最小实体增强是 TRANS 独立重闭合，但它不能替代四状态恢复。

不应恢复：用当前 P04B/R256 模型直接重跑旧 P05–P10；扩大事后频率搜索或分类器调参；把 final-test 解封；重复已经充分证明的 P04 中央腔体积剂量实验；把技术失败的同一接口无限 retry 而没有新的根因证据。

## 7. GEN-ENC 第一次监管审查

结论：`GUARDIAN_APPROVE_WITH_REQUIRED_DISCLOSURES` 仅适用于继续形成合同草案；`GUARDIAN_ESCALATE_USER_DECISION` 适用于是否执行。当前提案方向能恢复大量遗失内容，但还不足以批准运行。

必须加入的合同条款：

1. 明确 primary question 是四状态/连续方向可读性，还是一般离散状态编码；二状态只能作 sanity check。
2. 给 `H=A C B` 中 A/B/C 的物理语义、可观察等价类、不可识别性和尺度/置换不变性。
3. “稳定编码秩”必须相对预声明噪声、漂移、制造误差和状态扰动定义，并报告失败状态。
4. 随机多入口至少包含固定分布的无序基准；若主张超材料启发，需单独定义其物理家族，不能只用随机矩阵代称。
5. 同成本必须冻结材料体积、端口数、传感器数、带宽、插入损耗、几何包络和计算预算；反向设计必须有独立验证集与 `NO_IMPROVEMENT` 允许终态。
6. 有限全波验证先通过解析/简单拓扑资格，再验证 2–3 个判别性案例；不能用当前不可信 U4 模型直接升级 Level C。
7. 加入连续角度或至少未参与设计的中间角度，防止四个标签上的离散成功被误写为方向规律。
8. 明确哪些结果只属于 Level C，哪些才可支持实体/全波机制；任何后续实体验证需另行用户授权。

## 8. 需要用户讨论的优先清单

1. 是否确认原四方向/连续方向问题仍为论文主问题之一，而不是由二状态 TRANS 或 INFO-TOP 原理替代；
2. 是否授权 GEN-ENC 成为恢复主线，并接受其最低合同条款；
3. 是否把旧 P05–P10 定义为“当前模型合同关闭、科学问题仍开放”；
4. 是否恢复随机/超材料启发对照、同成本反向设计和有限全波验证；
5. 是否需要 SUP-3 或 TRANS 独立重闭合作为实体补强，及其与 GEN-ENC 的资源优先级。

在以上决定前，不应把 `INFO_TOP_4_CORE_THESIS_READY_OPTIONAL_MINIMAL_SUPPLEMENT` 解读为原始科研主线已经完整回答。
