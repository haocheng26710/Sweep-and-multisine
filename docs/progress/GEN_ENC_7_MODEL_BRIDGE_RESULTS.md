# GEN-ENC-7 MODEL-BRIDGE：五节点—九节点中央腔诊断

日期：2026-09-02  
终态：`MODEL_BRIDGE_FIVE_NODE_ADEQUATE_FOR_FIXED_REPRESENTATIVES`

## 结论

在四个结果盲预固定代表、8 个固定 development nuisance cells、2 个 repeats 和 208 个频点的范围内，把五节点模型的单一中央腔节点拆成五个中央腔控制体，并没有恢复代表之间的声学对比。

主九节点模型相对五节点基线的代表响应变化中位数仅为 0.236%–0.327%，4/4 均低于预声明的 1%可观测门槛。最弱代表距离相对变化为 −0.0082%，六对平均距离变化为 +0.0676%，远低于 20%对比恢复门槛。因此，当前结果不支持“单一中央腔节点是 OBS-A/B 重叠的主要原因”。

该终态只表示：**对于这四个固定代表、这一种物理约束下的低阶中央腔离散和当前频带，五节点近似已经足够接近九节点结果。** 它不等于五节点模型获得实体或全波验证。

- `HAND_01`
- `NEAR_01`

没有根据 OBS-A/B 数值重新挑选代表。nuisance cells 按 `LOWEST_8_SHA256(GEN_ENC_7_MODEL_BRIDGE_V1|cell|index)` 固定，保留两个 development repeats；不读取 validation/final-test。

预声明门禁为：

- 至少 2/4 代表的响应变化中位数达到 1%，才称空间分辨“可观测”；
- 主模型的最弱代表距离相对提高至少 20%，才称“恢复对比”；
- 若三个固定中央体积分配敏感性的最弱距离增益发生正负反转，则终态为离散化敏感、不可判断。

## 模型桥接

五节点基线为四个局部节点加一个均匀中央腔节点。九节点桥接模型为：

`四个局部节点 + 四个中央腔边界控制体 + 一个中心麦克风控制体`

每个扇区只连接与它对应的中央腔边界控制体；四个边界控制体再连接中心控制体。没有引入缺乏 CAD 依据的 sector-to-sector 直接边。

中央方形腔沿用冻结尺寸：半边长 18.102665 mm、高 9.2 mm。主划分把中央方形控制体边长固定为整个腔边长的一半，对应中心体积分数 0.25，四个边界体各 0.1875。边界到中心的有限体积连接长度为 0.75 倍半边长，截面积为半边长乘腔高。中央总体积严格保持不变。

另外固定中心体积分数 0.125 和 0.5 作为两端敏感性；它们不用于选择主结果。

## 对 OBS-A/B 的含义

MODEL-BRIDGE 将此前判断进一步收窄：

- OBS-A：家族差异在到达中央麦克风前已经重叠；
- OBS-B：现有 family-to-star 映射后的有效几何本身已广泛重叠；
- MODEL-BRIDGE：在小规模固定代表中，把均匀中央腔节点升级为低阶空间分辨中央腔，并没有恢复对比。

因此，目前最有证据支持的首要问题仍是“生成规则与 family-to-star 有效几何映射的组合没有产生充分分离的物理参数分布”，而不是中央腔只有一个节点。

但九节点模型仍是低阶模型：它没有完整二维/三维中央腔模态、相邻边界控制体的细网格耦合、复杂窗口位置效应、边界层损耗或实体制造误差。因此不能由本结果排除高保真 COMSOL 或实体装置中出现额外差异的可能。

## 技术修复与验证

首个 attempt-00 在诊断辅助函数中原地归一化输入数组，使第一个敏感性计算后五节点基线被修改，导致后续相对响应出现约 `3e7` 的伪放大。矩阵条件数检查未发现相应病态；根因定位后改为复制数组再归一化，并增加“不修改输入”的回归测试。attempt-00 不作为科学结果，最终合同和输出已由修复后的完整重跑覆盖。

最终验证包括：

- 九节点矩阵尺寸、有限性、被动性、互易性和中央体积守恒；
- 内部耦合趋强时九节点解收敛到五节点解；
- 差异度量不修改输入；
- 独立验证器从保存的四个 `(4,43)` 代表签名和三个 `(4,16,2)` 单元差异数组重算距离、汇总、门禁与终态；
- 输入文件 SHA-256、代表顺序和 scope seal 通过。

`validation_reads=0`，`final_test_read=false`，`m3_authorized=false`。

## 决策

不建议把 exact80 九节点扩展作为下一步，因为固定代表上的效应远低于门槛。若论文需要进一步回答“现实是否同样重叠”，下一项真正有增量的信息应来自小规模全波 COMSOL 或实体对照，而不是继续增加低阶中央节点。

本阶段不授权 exact80 扩展、M3 或实体因果主张。
