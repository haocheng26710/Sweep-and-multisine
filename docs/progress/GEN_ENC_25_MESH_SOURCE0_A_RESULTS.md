# GEN-ENC-25 MESH-SOURCE0-A 单入射方向网格定位

日期：2026-09-03

## 结论

上一阶段完整四端口 size3→size2 网格差异主要由 source 0 驱动。本阶段固定四角补偿、alpha=0.05、9.00 mm 物理颈长、全部物性和读出器，仅对 source 0 做更细网格与局部加密诊断。

全局 size2→size1 的复声压相对 L2 为 **2.025%**，低于冻结的 3% 门槛；单源跟踪频率保持 948 Hz，拟合深度从 12.000 dB 变为 11.912 dB，仅变化 -0.088 dB。因此 source 0 在全局 size2 上已经达到本项目的数值收敛标准。上一阶段失败不是 size2 自身不稳定，而是 size3 对该方向过粗。

三个仅加密颈管或颈管+侧腔域的低成本候选均未复现全局 size1，复响应差仍约 12%。本阶段没有找到可替代全局 size2 的局部网格补丁。

## 冻结比较

全局网格序列：

| 比较 | 复响应 L2 | 幅值 L2 | 最优复增益对齐后 L2 | 跟踪频率变化 | 深度变化 |
|---|---:|---:|---:|---:|---:|
| size3→size2 | 10.346% | 5.075% | 5.501% | 950→948 Hz | 12.321→12.000 dB |
| size2→size1 | **2.025%** | 1.355% | 0.961% | 948→948 Hz | 12.000→11.912 dB |

size2→size1 的最佳拟合复增益幅值为 1.0115、相位为 0.791°。频率、深度和完整复响应三项均通过冻结门槛。

这里的单源频率与上一阶段四方向平均读出的 954 Hz 不冲突：本阶段有意只读取 source 0，用于隔离网格异常，未重定义多源正式读出器。

局部候选均保留全局 size3，只改变选定域的自动网格等级：

| 候选 | 局部规则 | 单元数 | 相对全局 size1 的复响应 L2 | 结果 |

| LN2 | 颈管域 size2 | 16,757 | 12.092% | 失败 |

| LR2 | 颈管+侧腔域 size2 | 16,680 | 12.134% | 失败 |
| G1 | 全局 size1 | 47,463 | 参考 | — |

三种局部方案都保持约 950 Hz 的单源共振标记，但完整复场没有接近全局 size1。即只细化共振颈和侧腔无法修复 source 0 的相位/幅值误差。结果与误差主要来自主风道传播区域或其全局耦合离散相一致，但本阶段不把该数值定位提升为物理因果证明。
