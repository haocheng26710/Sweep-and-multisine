# TRANS-1 一体化双入口实体 pilot 结果

日期：2026-08-27  
终态：`TWO_PORT_SELECTIVE_ENCODING_SUPPORTED_WITH_LIMITS`

## 结论摘要

本次实体 pilot 提供了一个比既有四入口实验更直接的正面结果：在同一次闭合装配和固定测量条件下，`N` 与 `S` 两个状态产生了可重复、可定位的**去均值幅度频谱编码**。200–4000 Hz 的 N−S 谱形 RMS 为 **2.069 dB**（重复曲线 bootstrap 95% CI **2.056–2.188 dB**），是本批组内重复性 p95 **0.956 dB** 的 **2.165 倍**。返回 N 状态后，NRETURN−S 效应为 **2.079 dB**，与首次 N−S 差异曲线的 Pearson/cosine 相似度均为 **0.851**。

这说明降低共享腔混合并采用一体化双入口拓扑后，单麦克风能够读取两个不同状态留下的稳定频谱形状差异。它不是单纯的整体音量差，也不是只出现于某一次重复的异常。

不过，本批只有一次装配闭合、一个房间/距离和两个状态，且 REW 未使用 timing reference。因此结果尚不能证明跨装配、跨环境或四方向泛化，也不能验证相位/脉冲响应编码或 COMSOL 对实体局部峰位的精确预测。

## 固定分析规则

- 频率网格：200–8000 Hz，48 points/octave 对数网格。
- 平滑：插值后 1/12-octave dB smoothing。
- 主分析：200–4000 Hz；次要证据：4000–8000 Hz。
- 主效应：每条曲线在分析频带内去均值后计算状态代表谱差异，避免把整体声压级偏移误当作编码。
- 不确定性：以整条重复曲线为重采样单位，2000 次 bootstrap；未把频率点当作独立样本。
- 所有 15 次重复均保留；没有为了改善结论挑选 3–4 次或自动排除曲线。
- 固定窗口在查看本批效果前已经存在：1850/3800 Hz 模块目标窗口，以及 1538/4170 Hz R256 定位窗口；窗口均为中心 ±1/6 octave。
- 没有训练分类器、事后选频、参数搜索或更改既有阈值。

## QC 与重复性

15 个 TXT 均可解析并覆盖固定频带。每个样本标为 `warning`，原因不是曲线技术损坏，而是上传包中没有独立装配照片或人工闭合记录，且 no timing reference 使相位/IR 结论不可用。没有技术事故足以排除任何文件。

| 状态 | 重复数 | 主频带组内谱形 RMS 中位数 (dB) | 最大值 (dB) |
|---|---:|---:|---:|
| N | 6 | 0.892 | 0.999 |
| S | 6 | 0.332 | 0.592 |
| NRETURN | 3 | 0.368 | 0.405 |

本批所有状态内两两谱形差异的 p95 为 **0.956 dB**。历史 SUP-0 CONT p95 为 0.8793 dB；二者尺度接近，但本批采用 0.956 dB 作为更保守的当前重复性参照。

N 的离散度高于 S 和 NRETURN，必须保留为限制。不过，即使将每一条 N 重复与每一条 S 重复逐一比较，主频带谱形 RMS 仍为 **2.079–2.296 dB**，没有由单条异常驱动。

## 整体状态差异

| 指标 | 结果 |
|---|---:|
| N−S 去均值谱形 RMS，200–4000 Hz | 2.069 dB |
| 95% CI | 2.056–2.188 dB |
| NRETURN−S 去均值谱形 RMS | 2.079 dB |
| N−NRETURN 回程/时间漂移 | 1.131 dB |
| N−S / 当前重复性 p95 | 2.165× |
| N−S / N−NRETURN 漂移 | 1.829× |
| N−S 与 NRETURN−S Pearson/cosine | 0.851 / 0.851 |
| 次要频带 N−S 谱形 RMS，4000–8000 Hz | 2.636 dB |

NRETURN 控制很重要：它表明从 N 切换到 S 后再返回 N，差异模式大体恢复。回程并不完全重合，因此环境、时间或微小机械状态仍占有可见份额；但方向/状态效应大于回程漂移，并且两条状态差异曲线高度同形。

## 固定窗口结果

### 既有 1850/3800 Hz 模块目标窗口

| 固定窗口 | N−S (dB) | 95% CI (dB) | NRETURN−S (dB) |
|---|---:|---:|---:|
| 1850 Hz | +2.225 | +1.806 至 +2.506 | +2.662 |
| 3800 Hz | −0.527 | −0.712 至 −0.308 | +0.076 |
| 低频−高频联合对比 | **+2.753** | **+2.178 至 +3.094** | **+2.586** |

联合对比的物理含义是：相对于 S，N 在约 1850 Hz 更强、在约 3800 Hz 更弱，形成相反方向的双频带标记。该联合对比在回程 N 中维持同号，且远高于当前重复性 p95。

### R256 1538/4170 Hz 定位窗口

| 固定窗口 | N−S (dB) | 95% CI (dB) | NRETURN−S (dB) |
|---|---:|---:|---:|
| 1538 Hz | +0.665 | +0.005 至 +1.196 | +0.660 |
| 4170 Hz | −0.799 | −1.468 至 −0.135 | −1.381 |
| 低频−高频联合对比 | **+1.464** | **+0.338 至 +2.353** | **+2.041** |

该窗口对也表现为稳定同号的低−高频对比，但应称为**窗口级一致性**，不能称为 COMSOL 对实体峰位的准确预测。TRANS-1R256 的 coarse/fine 数值门禁未通过，因此模型没有获得精确预测实体局部谱形的资格。

## 科学解释

### 可以支持

1. 一体化双入口装置在单次闭合条件下可产生两个可重复读取的幅度频谱状态。
2. 编码包含多个频带间的相对变化，而不只是“同一首歌音量不同”。
3. N→S→NRETURN 的回程控制支持该差异与入口/状态切换有关，并非单次异常。
4. 1850/3800 Hz 的双窗口反向对比是本批最清楚、最有论文叙事价值的实体证据。
5. 与既有四入口共享腔实验相比，该结果支持“减少共享腔混合、降低状态维度后，编码信息更接近单麦克风可读范围”这一机制解释。

### 不能支持

1. 两个绝对空间方向或四方向的可靠定位。
2. 未见装配、其他房间、距离、扬声器或日期上的泛化。
3. 单个腔体或模块的独立因果贡献率。
4. 相位、到达时间、脉冲响应或多麦克风信息。
5. COMSOL 对实体频谱峰值、Q 或局部谱形的精确预测。
6. 监督分类精度或独立测试集性能；本批只有一个连续采集序列，运行分类器会乐观泄漏批次状态。

## 下一步决策

本结果足以把 TRANS 实体 pilot 纳入论文，并将叙事从“装置似乎不同”推进到“拓扑隔离后得到可重复的二状态频谱码”。建议下一主阶段进入 **INFO-TOP**：在仿真/模拟中系统比较传感器数量、噪声/漂移和拓扑编码维度之间的信息—成本关系。

不建议立即扩展成完整四方向、多个距离或大规模分类矩阵。若论文时间允许，最有价值的额外实体检查仅是一轮独立重闭合的最小复核（例如 N×3 → S×3 → NRETURN×3），用于把“单次闭合内稳定”升级为“跨闭合可复现”；它不是进入 INFO-TOP 的前置条件。
