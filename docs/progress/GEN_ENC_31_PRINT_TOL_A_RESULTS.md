# GEN-ENC-31 PRINT-TOL-A 有界有效几何公差

日期：2026-09-03  
本轮终态：`PRINT_TOL_A_STOP`；GEN-ENC-32 已闭合唯一网格哨兵并接受物理公差结论

## 结论

公差合同为有效颈长 9.00±0.20 mm、有效颈面积 ±2%、有效侧腔体积 ±2%。alpha=0.05 的六个单因素结果均按 Helmholtz 关系给出正确方向：短颈、较大面积或较小体积各使频率上移 8 Hz，反向扰动各使频率下移 8 Hz，深度保持 11.34–11.68 dB。

五档三因素同向叠加角点均有限、可见且不触及搜索边界。保守频率区间为 1120–1192、1020–1094、928–976、836–880、736–780 Hz；相邻最坏净间隔为 **26/44/48/56 Hz**，最小 26 Hz，高于预设 20 Hz 门槛。角点相对各自目标的最大绝对误差为 44 Hz，低于 45 Hz 门槛。

本轮两个预定网格哨兵中 alpha=0.07 高频角/source 0 的 size2→size1 为 2.124%，通过；alpha=0.03 低频角/source 2 为 6.117%，失败，故本轮自身停止。GEN-ENC-32 随后以 F26→F20 原始复 L2 2.884% 闭合该路径，因此物理公差结果最终可接受。

这些范围是模型中的“有效几何参数界限”，不是某台 FDM 打印机的经验误差分布，也不表示三个误差必然独立或等概率。

产物包括 18 个 MPH、66 条有限复谱、单因素和十个保守组合角点。正式入口为 `scripts/gen_enc_31_print_tol_a/` 及分析脚本。未提交，未 push。
