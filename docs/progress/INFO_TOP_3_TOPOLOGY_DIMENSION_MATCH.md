## 1. 结论摘要

三类拓扑在统一四状态、统一 16 窗口谱基底、统一四传感器观察矩阵、相同噪声/漂移单位、相同开发/评估参数单元和同一评价代码下技术可比。结果支持两个有界 Level C 判断：`H-COUPLING=SUPPORTED_WITH_LIMITS`，`H-MATCH=SUPPORTED_WITH_LIMITS`。这不是实体或 COMSOL 因果确认；耦合系数是结果前冻结的结构代表值，不是测得的真实参数。

H-COUPLING 的独立评估 headline 使用全部四个固定 M=1 传感器角色，不使用最佳组合。主参考扰动下 minimum pairwise between/within 的四角色中位数依次为高共享 `0.2581`、中等隔离 `0.5147`、近独立 `0.6052`；4/4 角色均满足近独立 > 中等 > 高共享，500 次成对完整参数单元 bootstrap 的严格三档顺序概率为 `1.000`。

H-MATCH 使用相对冻结 nuisance floor 的稳定对比维度，不以 M 或 raw rank 代替。开发选择、独立评估的 12 行中，完整 3/3 稳定覆盖只出现在近独立拓扑的 M=2 和 M=4；两行主要指标中位数为 `1.1151`，其余不完整覆盖行为 `0.5330`，500 次成对完整评估单元 bootstrap 的非劣概率为 `1.000`。近独立 M=3 的稳定维度由 3 降为 2，同时主要指标由 M2 的 `1.0906` 降至 `0.9505`；M4 恢复 3/3 后升至 `1.1395`。这与“稳定可用对比维度覆盖编码所需三维时提高或平台化、维度瓶颈时下降”的冻结模式一致，但仍只是相关的降阶结构证据。

## 5. 两项预声明消融

`REMOVE_COMMON_MODE_KEEP_MODULE_SIGNATURES` 将 K 置为 I4，保留 A/B/D/F 签名。三类原拓扑因此按定义收敛到同一参考：四角色 M1 ratio 中位数 `0.6129`，M4 为 `1.1544`。它高于原高共享 M1 的 `0.2581`，表明本模型中的共享混合是可读性损失来源。

`HOMOGENIZE_MODULE_SIGNATURES_KEEP_COUPLING` 抹平 A/B/D/F 差异而保留各 K。M1 ratio 中位数仅 `0.0720` 左右，M4 约 `0.0826`，三拓扑近乎重合在扰动底线。这说明耦合矩阵本身不能在没有模块谱差时生成本次四状态码。

两个消融共同支持“局部谱差是编码来源，共享混合压缩其可读对比”的 Level C 解释；它们不识别实体中单个模块贡献率。

## 7. COMSOL、TOP-4 与论文结论

不生成 `limited_comsol_anchor_request.json`。当前两项判断由预声明的结构包络、真实谱基底和完整扰动扫描共同给出；没有一个至多 2–3 点的 COMSOL 锚点能够在不先建立可信四状态实体模型的情况下改变判定。P04T5/R256 又明确限制现有模型的局部预测资格，所以本阶段不请求有限 COMSOL。

最重要的论文可用结论是：

> 在由真实单入口模块谱签名锚定、但耦合强度仅作结构包络的四状态降阶模型中，降低共享混合一致提高了全部单传感器角色的最差状态对可读性；当稳定可用的三条对比维度覆盖四状态所需的三维编码空间时，鲁棒分离提高或恢复，而维度瓶颈伴随性能下降。该结果支持拓扑隔离与维度匹配的设计原则，但不能确认实体耦合因果系数或单模块贡献。
