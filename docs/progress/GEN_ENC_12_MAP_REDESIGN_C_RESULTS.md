# GEN-ENC-12 MAP-REDESIGN-C 合流—节流静态原型

## 设计与防偏差修正

C 轮沿用 B1 的 HAND、RANDOM 和 PHYSICS 映射，只改变 NEAR：

- C0 是 B1 对照，NEAR 为两条全长对称通道；
- C1 让 shared 参数共同控制两条 NEAR 通道的 2–6 mm 长度；
- C2 让两条 NEAR 通道先对称传播 3 mm，再进入 1 mm 长、26 mm 宽的合流腔，最后通过 2 mm 长的中央节流段；节流宽度由 shared 参数控制。

首次原型运行误把新增的 role-volume 特征加入共同观察基底，使 C0 从 B1 的 0.9244 人为升至 1.1855。该选择立即作废。修正后恢复 GEN-ENC-11 的共同特征基底，只允许 C2 增加其真实存在的 merge 拓扑量；C0 精确复现 B1 的全部关键比值，证明跨轮比较口径恢复一致。

本轮只读取 exact80 身份参数和静态几何，不读取或计算声学响应。候选顺序与“首个通过即选择”的规则在查看结果前固定为 C0、C1、C2。

为排除离散 merge 指示量直接抬高结果，又删除该指示量并只保留尺寸、面积和分段等几何特征重算。C2 的全局最小仍为 1.1367，限制对为 NEAR–RANDOM，仍通过门限；因此静态通过不是由单一拓扑标签造成。
