# GEN-ENC-9 HAND–NEAR 损耗与三维桥接诊断

## 范围

本轮固定 HAND_01 和 NEAR_01，只检验稀疏抽样、无损窄共振、纯维度效应和真实截面三维效应。二维密扫为 250–1500 Hz 的 161 个对数频点和四端口；共同复声速损耗因子固定为 0、0.005、0.02。三维锚点固定为原网格索引 38、113、132，即 346.215、1022.598、1345.434 Hz。

三维同时构造等效面积挤出对照与真实段截面模型。后者恢复 2×2 mm 连接器、17×6.2 mm 腔体、8.2 mm 内部台阶和 9.2 mm 外 collar。

## 二维密扫

| 损耗因子 | HAND–NEAR 签名距离 |
|---:|---:|
| 0 | 0.09483 |
| 0.005 | 0.04894 |
| 0.02 | 0.04746 |

密扫没有推翻重叠；加入损耗后距离约减半。无损窄峰不是二者接近的原因，反而提供了部分可区分细节。

## 三维与网格

无损三维固定频点对网格敏感，不能用于幅值结论。加入损耗因子 0.02 并继续到 automatic size 1 后：

| 相邻细网格 | 全响应相对 L2 | 签名变化 |
|---|---:|---:|
| HAND size 2→1 | 1.271% | 0.00846 |
| NEAR size 2→1 | 1.596% | 0.01078 |

两者均通过 L2 不高于 2%、签名变化不高于 0.05 的门禁。共同 size 1 的真实截面三维 HAND–NEAR 距离为 0.05260，仍是强重叠。

二维与等效面积三维挤出对照的响应差约 2%–3%；恢复真实截面后绝对响应改变约 36%–49%。真实截面明显改变波场，但没有把 HAND_01 和 NEAR_01 明显分开。

## 结论

终态：GEN_ENC_9_HAND_NEAR_OVERLAP_PERSISTS_UNDER_BOUNDED_CONTROLS。

证据更支持：HAND_01–NEAR_01 的接近主要随 family-to-star 有效几何映射保留下来，不是单纯由中央五节点塌缩、十二点稀疏抽样、无损假设或二维厚度平均造成。

这不证明现实制造件必然重叠。损耗未标定，真实截面仍是块体近似，没有完整窗口三维布局、热黏边界层、圆角、传感器实体与制造误差。论文中稳妥的表述是：低阶与全波模型细节并不等价，但本次有损二维密扫和收敛三维 spot-check 均未消除最危险的 HAND–NEAR 重叠。
