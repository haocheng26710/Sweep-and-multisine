# GEN-ENC-26 PRINT-CONV-B 全局 size2 三端点确认

日期：2026-09-03  
终态：`PRINT_CONV_B_MESH_STOP`

## 结论

固定四角等体积补偿、2×4 mm 矩形颈管和 9.00 mm 物理颈长后，全局 size2 的 alpha=0.03/0.05/0.07 四方向平均读出为 **1152/954/756 Hz**，相对 1150/950/750 Hz 的误差仅 +2/+4/+6 Hz。三档严格单调、全部超过冻结可见度门槛并明显强于各自同网格背景。因此可打印三维模型中的目标频率映射在统一 size2 网格上继续成立。

但 12 条“alpha×声源方向”相邻网格收敛路径中有 1 条失败：alpha=0.03/source 2 的 size2→size1 完整复响应 L2 为 **4.861%**，超过 3% 门槛。其余 11 条均通过。按预先冻结规则，本阶段终态仍为失败，不开启 alpha=0.04/0.06 盲点或制造公差。

## 冻结自适应网格规则

端点先计算 size3→size2。超过 3% 的路径才补算 size1，并以 size2→size1 作最终判定。该规则在读取端点结果前冻结。

- alpha=0.03：source 0/1/2 的 size3→size2 分别为 12.730%/3.256%/5.166%，触发 size1；source 3 为 2.084%，直接通过。
- alpha=0.07：source 0 为 3.001%，触发 size1；source 1/2/3 为 2.031%/1.878%/1.762%，直接通过。
- alpha=0.05 沿用上一阶段冻结证据：source 0 的 size2→size1 为 2.025%；source 1/2/3 的 size3→size2 为 2.657%/2.046%/1.719%。

触发的 size2→size1 结果：

|---:|---:|---:|---|
| 0.03 | 0 | 2.344% | 通过 |
| 0.03 | 1 | 2.715% | 通过 |

最终 11/12 路径通过，但冻结门禁要求 12/12，因此不能把接近全通过解释为整体通过。

## 唯一失败路径的只读诊断

结果后只读分解不改变门禁。alpha=0.03/source 2 的 size2→size1 指标为：

- 原始完整复响应 L2：4.861%；
- 幅值响应 L2：2.160%；
- 最佳单一复增益对齐后 L2：2.604%；
- 最佳增益幅值：1.0035；相位：2.348°；
- 单源跟踪频率：1132→1130 Hz；
- 单源拟合深度：11.877→11.816 dB。

共振中心、深度和幅值谱形已较稳定，失败主要由绝对复相位差驱动。但当前冻结门禁明确评估原始完整复响应，不能在看到结果后改成幅值或相位对齐指标。

## 阶段边界与下一方向

本阶段支持“统一 size2 上三端点频率映射与可见度稳定”，不支持“所有四方向完整复响应均已数值收敛”。因此不打开 alpha=0.04/0.06，不运行公差、validation/final-test，也不形成论文实体性能主张。

若继续，下一阶段应是单路径的 `A03-S2-PHASE-MESH-A`：仅针对 alpha=0.03/source 2，预先冻结一个比自动 size1 更细的自定义全局网格，并同时审计源边界相位参考。优先目标是判断 2.35° 的整体相位差是否随进一步加密收敛；不能重新校准颈长或修改读出阈值。
