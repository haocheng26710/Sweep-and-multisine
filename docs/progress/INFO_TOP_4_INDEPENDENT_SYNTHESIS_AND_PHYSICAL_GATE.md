## 1. 独立裁决摘要

论文核心已经具备完整故事，不需要新的打印、测量或 COMSOL 才能成立。核心贡献不是“已实现可靠四方向识别”，而是：**以分层真实证据、阴性读出结果和有边界的降阶研究，解释形态学频谱编码为何可测却难以稳定解码，并提出“局部谱差—共享混合—稳定对比维度—观测能力”必须匹配的设计原则。**

最强结论是 TRANS 在单次闭合内实现了有限、可重复的二状态实体频谱选择性；次强结论是单入口模块和共享腔体积干预都能产生真实、可重复的谱签名/重分配，但组合后的单模块贡献不可独立识别。明确阴性结论是旧 U4 未实现可靠四方向 grouped readout，简化 COMSOL 也未取得精确预测实体局部峰谷的资格。

TOP-2/3 给论文增加的是**理论与方法层面的设计原则**，不是新的物理验证。TOP-2 保持 `INCONCLUSIVE`；TOP-3 的机器标签保留为冻结规则结果，但本次独立论文裁决将 H-COUPLING 和 H-MATCH 均限制为 `PARTIALLY_SUPPORTED`。Level C 与真实数据没有合并为总体效应。

## 4. 八项主张裁决

### 4.1 真实装置能产生可重复频谱变化 — `SUPPORTED`

直接证据：TRANS N−S 主频带去均值谱形 RMS `2.0695 dB`，为本批组内 p95 `0.9558 dB` 的 `2.1653×`；NRETURN−S 效应为 `2.0792 dB`，与首次效应相关 `0.8513`。U4 和 P04 也分别提供受限方向谱差与实体体积干预证据。

限制：这些结果仍受单/少数装配、房间、距离、采集顺序和漂移限制。论文可写：“在已测试装配和测量条件下，实体装置产生了超过对应重复性底线的可重复幅度频谱变化。”

### 4.2 单入口 A–H/A-B-D-F 模块具有真实可重复签名 — `SUPPORTED`

直接证据：SUP-1 中 28/28 模块对的完整主频带代表谱距离超过 FORMAL CONT p95，且每对 9/9 跨重复组合超过底线。

限制：A/C 重复性较弱；SUP 数据仍为 `scientifically_eligible=false`；隔离模块签名不能自动解释集成阵列中的独立贡献。允许措辞：“隔离单入口模块显示可区分的可重复谱签名，其中 A、C 需更谨慎解释。”

### 4.3 旧 U4 实现可靠四方向识别 — `NEGATIVE`

直接证据：U4SYM/U4ENC grouped balanced accuracy 分别为 `0.375/0.250`，均低于冻结的 `0.50` 实用目标。虽然 worst-case 谱形/组内比为 `2.0437/2.5199`，谱差没有转化为可靠 grouped readout。

限制：这是对“已实现可靠识别”主张的否定，不代表所有谱差为零。论文应写：“旧 U4 产生方向相关谱差，但未实现可靠四方向识别。”

### 4.4 TRANS 两通道实现有限二状态选择性编码 — `SUPPORTED`

直接证据：除整体谱形效应外，1850/3800 Hz 冻结双窗对比为 `2.7528 dB`，95% CI `2.1781–3.0941 dB`，回程保持同号。

限制：只覆盖两个状态、一次闭合与幅度谱。论文应保留“有限、单次闭合内、二状态”三个限定词。

### 4.5 降低共享混合改善可读性（H-COUPLING）— `PARTIALLY_SUPPORTED`

直接证据：TOP-3 在全部四个固定 M=1 角色上得到近独立 > 中等隔离 > 高共享，中位 minimum-pair ratio 为 `0.6052 > 0.5147 > 0.2581`；移除 common mode 后三拓扑按定义收敛。

反证/限制：这是由真实谱基底与预声明 `K(alpha)` 构成的 Level C 结果。该共同平均结构本身会随着 alpha 增大压缩中心化状态差；alpha 不是实体测得的耦合系数。成对 bootstrap `1.000` 只表示冻结模型与完整参数单元重采样下的顺序稳定，不是实体机制为真的概率。

允许措辞：“在预声明混合矩阵与真实谱基底构成的 Level C 模型中，隔离趋势稳健。”不得提升为实体因果确认。

### 4.6 稳定编码维度与观测维度匹配有利（H-MATCH）— `PARTIALLY_SUPPORTED`

直接证据：完整 3/3 稳定覆盖两行的主要指标中位数为 `1.1151`，其余十行为 `0.5330`；近独立 M2 的 3/3 覆盖与 ratio `1.0906`，M3 降至 2/3 与 `0.9505`，M4 恢复 3/3 与 `1.1395`。

反证/限制：完整覆盖只发生在近独立拓扑，耦合强弱和维度覆盖混杂；机器 `SUPPORTED_WITH_LIMITS` 是冻结规则输出，不足以成为独立物理确认。允许措辞：“结果与稳定对比维度覆盖有利的假设一致，但仅构成有限结构证据。”

### 4.7 麦克风数遵循对数或稳定边际递减（H-COUNT）— `UNCERTAIN`

直接证据：TOP-2 两包络 M1–M4 主 ratio 分别为 `0.60379, 0.60998, 0.60887, 0.60671` 与 `0.66842, 0.67047, 0.66383, 0.65805`。全部边际为正 bootstrap 概率仅 `0.056/0.002`，严格递减概率 `0.498/0.338`。

限制：四个 M 点下对数、饱和和幂律弱可识别；没有实体多麦数据。M2 只可称条件性 Level C Pareto 拐点，不能称两个麦克风实体最优。

### 4.8 确认单模块独立贡献率、实体耦合系数或部署级方向识别 — `NEGATIVE`

现有设计不识别这些量：HET-ABDF 同时改变三个模块；TOP-3 alpha 为给定结构参数；U4 grouped readout 未达门槛；没有部署验证。这里的 `NEGATIVE` 表示“当前确认主张不成立”，不是说真实贡献或耦合为零。

## 5. 论文故事线

1. 原始目标是用形态学多入口结构把方向/状态编码到频谱。
2. 旧 U4 的真实结果显示：共同腔混合、装配和漂移可以产生复杂谱结构，但复杂度没有转化为稳定四方向 readout。
3. SUP-1/SUP-2R 与 P04 把机制拆开：单入口模块确有真实谱签名，共享腔体积也可控制宽频重分配；但组合不是简单叠加，独立模块贡献不可识别。
4. TRANS 通过降低任务状态数并采用一体化双入口结构，在实体上获得有限、可重复的二状态选择性。
5. R256/P04T3 诚实限定简化 COMSOL：它能给趋势或窗口锚点，不能精确预测实体局部峰谷。
6. TOP-2/3 把失败转为设计原则：更多频谱复杂度或更多麦克风不是目标；编码维度、条件数、抗共同漂移能力与观察能力必须匹配。
7. 本论文实际完成的是上述真实证据链、阴性边界、有限实体正结果和 Level C 结构分析。实体近独立四状态、装配一体化的跨闭合验证及必要时有限多麦验证属于 future work。

相比只写“似乎有方向差异”，本研究建立了重复性底线、分离“谱差存在”和“readout 可用”、定位真实单入口谱源、证明组合不具简单可加性、给出二状态实体正结果，并把四状态和 COMSOL 失败转化为明确的可识别性与设计边界。
