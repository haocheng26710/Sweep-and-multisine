# V2.5 不理想时的递进式仿真与改版路线

日期：2026-08-24

## 总原则

本路线只在 V2.5 三阶段数据完成后启用。先根据 S1/S2/S3 定位失败层级，再选择最小足够方案；不得因为总体分类较低就同时修改共振器、共同腔和外部入口。

没有任何方案能保证论文录用。目标是把结果组织成可复现、可证伪、具有机理解释和实验验证的工程贡献，而不是追求一个经过事后调参的高分类分数。

## 先判定失败发生在哪里

| V2.5 观测 | 主要问题 | 优先路线 |
|---|---|---|
| S1 峰/谷稳定，S3 仍有方向差，但分类不稳 | 特征标定、整体增益或 block 泛化 | 方案 1 |
| S1 峰/谷稳定但偏移、相邻模态重叠 | 模块调谐/Q/频率间距 | 方案 2 |
| S1 正常，但装入 S3 后模态消失、合并或大幅漂移 | 共同腔和通道耦合 | 方案 3A |
| S3 保留四个模态，但四个方向的通道向量相似 | 外部角度选择性不足 | 方案 3B |
| S1 本身不稳定且效应接近同时段重复性 | 密封、打印实现或 lumped 假设失败 | 先 QC；随后方案 2，不进入方向优化 |

## 方案 1：零重打——实测校准、现有模块重组与机理分析

### 改动程度

最小。不打印新零件；优先只使用已采集数据。若必须验证重新映射，仅重组现有 HR01–HR08，不修改主体。

### 适用条件

- S1 的实际模态可重复；
- S3 中存在大于同时段重复性的方向差异；
- 主要问题是目标中心偏移、总音量掩盖局部差异或原四个模块并非实测最优组合。

如果所有方向效应都落在重复性范围内，本方案不能凭分析“制造”方向性。

### 仿真/分析工作

1. 用 B01 S1 拟合一个两颈腔体 + 中心腔的 0D/1D 声学阻抗网络；自由参数限于有效颈长、损耗/Q、腔体顺应性和共同腔耦合。
2. 完全冻结参数后预测 B02 的峰值、带宽和相对幅度。只有 B02 预测通过，模型才用于设计判断。
3. 用 B01 从八个现有模块中选择四个，使实测中心间距相对于半功率带宽最大，同时限制插入损耗差和装配漂移。
4. 方向特征使用目标通道局部能量、去均值谱形及归一化通道向量；不得在 B02 上重新挑频或调整模型。
5. 如需新验证，只用现有模块重组一次 U4，执行四方向 × 3 次 × 2 blocks；不打印新件。

建议使用非重叠指标：

`Sij = |fi - fj| / (BWi/2 + BWj/2)`。

`Sij > 1` 表示两个 -3 dB 半带宽在该近似下不重叠；它是工程筛选量，不等于分类成功。

### 可形成的论文贡献

- 被动频率编码器的实验系统辨识；
- 名义设计频率、实测模态和装配漂移之间的定量关系；
- 共同增益归一化前后的方向通道结构；
- 数据驱动但由独立 block 验证的现有模块选择。

这是成本最低的路线，但发表上限也最低。它要求至少存在稳定物理效应，不能只靠分类器优化。

### 升级门槛

若 B02 无法验证 B01 拟合模型，或最优四模块仍严重重叠，升级方案 2。若模块单独正常但全阵列失真，跳到方案 3A。

## 方案 2：小到中改——仿真调谐，最多重打小插件或四个模块

### 改动程度

保留 P01/P02、麦克风位置、转盘和总体外形。优先设计可插拔颈长套筒、腔体填充块或新薄盖；如果现有结构不能可靠容纳插件，最多重打四个 HR tray/lid/gasket，不重打整机。

### 适用条件

- S1 模态可见，但频率偏移或带宽导致通道重叠；
- 或 S1 显示 HR01–HR08 的实际顺序大体成立，但 CAD lumped estimate 精度不足。

### 仿真层级

1. 先用方案 1 的校准声学网络做大范围参数扫描，排除明显不合格组合。
2. 对候选四模块进行 3D 频域压力声学仿真；颈部和狭窄通道加入等效粘热损耗，必要时对局部颈部使用完整 thermoviscous 子模型。
3. 对腔体体积、内外颈有效长度/面积、打印误差和密封缝隙做敏感性分析。
4. 只把最优少数方案放入完整 U4 模型，计算麦克风处传递函数和四通道串扰。
5. 以“频率分离、适中 Q、低串扰、相近宽带插入损耗、对 ±0.2 mm 打印误差稳健”为联合目标，不只追求尖锐高 Q。

### 最小实物验证

- 四个最终模块单入口各 3 次：12 份；
- 最终 U4 四方向 × 3 次 × 2 blocks：24 份；
- 合计 36 份新测量；S2 直管控制可复用同一次 V2.5 活动数据，但必须说明时间差。

如果使用插件，先打印一组小型尺寸/密封 coupon；不要直接重打整个头部。

### 可形成的论文贡献

- 实测校准的仿真—实验调谐流程；
- 设计参数、实测频率、Q 和制造容差的定量关系；
- 四通道频率正交性和阵列串扰的预测与验证；
- 相比第一代 P06 的明确设计改进机制。

这通常是风险、工作量和发表深度最平衡的路线。

### 升级门槛

若单模块仿真/实测一致，但完整 U4 仍破坏模态，模块继续调谐已经无效，应升级方案 3A。若模态保留而方向差弱，升级方案 3B。

## 方案 3：架构级改版——仿真联合设计，最终只打印一个验证版本

### 改动程度

最大，但通过多层仿真筛掉绝大多数实物迭代。只在最终候选通过网格、损耗和容差检查后，打印一个验证原型；在此之前最多打印一个两端口或四分之一结构 coupon。

### 方案 3A：解决共同腔耦合

适用于 S1 正常、S3 模态合并。

优先设计变量：

- 将四条通道独立延伸到更接近麦克风的位置；
- 缩小共同混合腔，避免四个共振器在大腔中形成强并联负载；
- 在各内颈后加入可控声阻抗/阻尼段；
- 设计可更换的小型汇合器，而不是重做整个外壳；
- 让各通道宽带插入损耗接近，减少单一强通道支配中心麦克风。

仿真应输出四端口到麦克风的传递矩阵、互易串扰、模态分裂、压力场和制造容差，而不只输出一条 SPL 曲线。

### 方案 3B：解决角度选择性

适用于频率码在 S3 中保留，但四方向响应相似。

优先设计变量：

- 外入口的短号角、导向唇或加深入口；
- 入口之间的径向隔板/遮蔽；
- 入口口径和方向性结构，但保持内部共振器不变；
- 必要时利用频率与装置直径的关系，重新选择四个工作频率，使外场相位/遮蔽差异更明显。

必须先做完整外场模型：以 0°/90°/180°/270°平面波入射，使用辐射边界、PML 或 BEM，并读取中心麦克风四个目标频带。仅仿真内部腔体不能预测方向性。

### 推荐多层模型

1. 0D/1D 阻抗网络：筛选上百组参数；
2. 单模块 3D FEM：校准频率、Q 和粘热损耗；
3. 完整内部 U4 FEM：计算共同腔模态和串扰；
4. 外部声场 + 内部耦合：计算四个入射方向；
5. 对最终 2–3 个候选做网格收敛、材料/温度/尺寸容差和边界条件敏感性；
6. 只打印最终候选并完成一次物理验证。

### 可形成的论文贡献

- 单麦克风被动频谱编码器的仿真—实验协同设计；
- 频率正交性与角度选择性的联合目标，而非事后分类器优化；
- 共同腔耦合或外入口方向性的明确失效机理；
- 制造容差下的鲁棒设计和最终实验验证。

这是发表潜力最高、工作量也最大的方案。若完全不打印最终候选，只能安全地写成数值设计/可行性研究，不能声称新硬件已获得真实方向性能。

## 推荐软件路线

### 有 COMSOL Acoustics Module

优先使用 Pressure Acoustics, Frequency Domain；规则狭窄通道采用 Narrow Region Acoustics，复杂狭窄颈部局部采用 Thermoviscous Acoustics。完整外场使用背景平面波和辐射域/PML。不要对整个外部空气域使用完整 thermoviscous 模型，计算代价不必要地高。

### 没有 COMSOL

- Gmsh 负责 STEP/STL 清理和体网格；
- DOLFINx/FEniCSx 或 FreeFEM 求解复数 Helmholtz 方程；
- 外部无限域使用 PML 或 FEM–BEM；
- 狭窄通道损耗以经过 S1 实测校准的复波数/阻抗边界近似。

开源路线可以完成研究，但粘热损耗、阻抗边界、外域处理和网格收敛需要自行验证，开发风险明显高于 COMSOL。若学校有 COMSOL 许可，论文时间尺度下优先使用许可软件。

## 建议的最终选择

默认顺序是：先执行方案 1 的失败诊断；若需要物理调谐，进入方案 2；只有数据明确指向共同腔或角度选择性时，才进入对应的方案 3A/3B。

最推荐的发表导向组合是：

> 既有 P06/FORMAL/SUP 数据作为第一代实验依据 + V2.5 三阶段实测定位失败层级 + 经过 B02 验证的仿真模型 + 最多一次小规模最终实物验证。

这比连续打印多个未经验证的版本更节省时间，也比纯仿真或纯分类结果更具可信度。

## S1–S3 数据后的路线选择（2026-08-24）

联合分析已经满足“差异存在但预定码未保留”的诊断条件：U4HR 的方向谱效应大于 U4SYM，但 HR01/HR03/HR05/HR07 固定方向—频率对角映射未成立；U4SYM 本身也具有强同 campaign 方向标签。当前优先进入 **方案 3A 的无打印仿真阶段**，输出四端口传递矩阵并追踪约 1.62、2.20、3.97、6.49 kHz 的耦合模态。

不建议直接进入方案 2 重打另一组 HR，因为单模块中心顺序和误差已经较好；也不建议先通过缩短 0.8 m 距离来追求分类率。若多端口模型证明内部码能够保持、剩余瓶颈才是入口角度门控，再升级到 3B。完整实测依据见 `V25_S1_S2_S3_JOINT_RESULTS.md`。

## P04T5最终路线状态（2026-08-26）

P04T2–P04T4已经形成可发表的有界机制证据：中央共享腔有效空气体积可引发剂量有序、跨批次可重复的宽频谱重分配，同时装配/基线状态不可忽略。该结果关闭本路线此前“继续旧Scheme 3A完整U4仿真”的默认建议。

P04B-N仍为`MODEL NOT CREDIBLE FOR U4`，P04C没有修复门禁，P04T3确认模型只能预测体积控制趋势、不能精确预测实体局部峰谷。故旧P05–P10在当前模型契约下为`BLOCKED_AND_CLOSED_UNDER_CURRENT_CONTRACT`，不得直接启动。只有未来出现新的、可验证的模型修复依据，并另行冻结全新模型契约后，才可重新提出独立授权；这不是当前路线的自动后续步骤。最终决策见`COMSOL_3A_P04T5_PUBLICATION_SYNTHESIS_AND_P05_GATE_DECISION.md`。
