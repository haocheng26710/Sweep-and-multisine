# P04T2 集成式中央腔插入件：小样本分级装配与采集手册

状态：`PILOT PLAN FROZEN — WAITING FOR P04T1V GATE`

## 1. 目的与边界

本实验只回答：在单入口 HR03 装配中，改变中央共享腔的可用空气体积，是否产生大于既有实体重复误差、方向符合仿真预期的固定频带变化。

这不是方向分类实验，也不检验完整 U4，不估计单模块因果贡献率。本轮不需要反复完成多个完整重装 block，但连续重复不能代替装配重复。因此采用：

- 每个状态只闭合一次并连续测量4次；
- 在末尾只重新装回一次 BASE，用于检查时间漂移和装配偏移；
- 先分析16条小样本 pilot；
- 只有结果有价值时，才对最有信息量的状态补一次6次确认。

不得读取 final-test，不改变既有正式实验 ACTIVE/EXCLUDED，不覆盖任何原始 TXT/MDAT。

## 2. P04T1V 对采集范围的控制

开始实体采集前先取得 P04T1V 终态：

- `P04T1V PASS_FOR_PRINT_AND_P04T2`：执行 BASE0、I75A、I50PA、BASE1，共16次；
- `P04T1V I75_PASS_I50P_NOT_AUTHORIZED`：只执行 BASE0、I75A、BASE1，共12次；
- `P04T1V PRINT_GATE_FAILED`：不执行 P04T2。

I50P 的实际空气保留比例为54.058706%，不是精确50%。文件名仍使用冻结条件码 `I50P`，报告中必须同时写明实际比例。

## 3. 全部状态共用的固定装配

装置和声源方向在本实验中不旋转。0°始终朝向扬声器并保持既有约0.8 m几何；开始前实测并记录装置中心到扬声器基准点的距离。

四个主方向保持单入口 S1：

- 0°：HR03，开放；
- 90°：P05＋P10，密封；
- 180°：P05＋P10，密封；
- 270°：P05＋P10，密封。

四个对角位置45°、135°、225°、315°按条件更换：

- BASE：四个原始 P09；
- I75：四个 P09＋I75 集成组合件，空气保留75.826042%；
- I50P：四个 P09＋I50P 集成组合件，空气保留54.058706%。

集成件的 P09 端朝外、叶片朝中央。四件必须属于同一条件，禁止 I75/I50P 混装。P01、P03、HR03、P05/P10、P06/P07和P02的其余装配方式不变。

## 4. 每次闭合的装配步骤

1. 停止 sweep，保持扬声器、麦克风、支架和桌面定位不动。
2. 打开 P02/P07，只更换四个对角 P09 或集成组合件；不要拆动 HR03、P05/P10 或麦克风。
3. 确认四个组合件完全落座、没有翘起或摇晃；中央叶片不得侵入0°/90°/180°/270°开放十字通路。
4. 按原顺序装回 P07，再装 P02。P02必须自然闭合，不得用额外压力强行压平。
5. 闭合后从顶部和0°基准方向各拍一张照片，记录 `assembly_id`。
6. 等待约30秒；期间不移动装置。
7. 连续完成该状态4次 sweep。四次之间不得触碰装置、线缆、音量或REW设置。

不需要胶水。若任何组合件在P01槽位与P02压紧后仍能移动，停止该状态，不以胶水临时补救；先记录机械异常。

## 5. 固定测量设置

- REW V5.31.3；
- 48 kHz，256k，REW repetitions=1；
- No timing reference；
- Set t=0 at IR peak；
- 完整保存200–8000 Hz；
- sweep level `-30 dBFS`；
- Windows输出50；
- iMM-6C输入100；
- 麦克风校准文件 `CMM29939.txt`；
- Windows增强、AGC、EQ和空间音效关闭；
- 扬声器旋钮、设备、房间、距离、装置高度、麦克风位置和0°方向全程不变。

后续预处理继续使用200–8000 Hz、48 PPo公共对数网格和1/12-octave dB smoothing；200–4000 Hz为主频带，4000–8000 Hz为次要证据。No timing reference，因此绝对相位不是确认性结果。

## 7. 异常处理和重复规则

- 四次正常测量全部保留，pilot代表值使用四条曲线的逐频率中位数；不自动删除“最差的一次”。
- 若发生门响、说话、碰线、REW报错、削波或明显中断，原文件仍保留并在notes标记 `TECH_FLAG`。
- 技术异常后可立即增加 `R05`，但不能覆盖R01–R04，也不能把普通谱形差异事后称为技术事故。
- 若连续两条出现同类异常，停止该状态，先检查硬件和环境。

每条记录至少包含：日期时间、文件主名、condition、assembly_id、repeat、四个对角件身份、0°单入口身份、实测距离mm、REW设置、校准文件、是否有人为噪声/触碰/削波、备注。

## 8. pilot 分析与停止门

上传16条TXT和对应MDAT、notes及装配照片后再分析，不根据REW画面临时改变采集顺序或频带。

分析使用全部重复和固定预处理，并至少检查：

1. BASE0与BASE1的差异是否小于既有HR03局部实体p95底线1.396 dB；
2. I75−BASE在冻结的约1646.88 Hz与1986.97 Hz附近是否分别保持负/正方向；
3. I75的变化是否在固定局部频带超过1.396 dB，且四条重复方向基本一致；
4. I50P是否继续移动同一谱形/分支，还是只产生无规律宽带变化；
5. 变化是否集中在主频带而不是由单条异常或高频噪声驱动。

pilot 后只允许三种决策：

- `STOP_SUFFICIENT_FOR_EXPLORATORY_MECHANISM`：效果清楚、BASE回返稳定；当前pilot已足够支持探索性实体机制证据，不补大量block。
- `ONE_CONFIRMATION_MINIBLOCK`：效果有潜力但需要最小装配确认；只选最有信息量的插入状态，重新装BASE测6次，再重新装该插入状态测6次，共12次。
- `STOP_NO_USEFUL_EFFECT`：变化未超过底线、方向不稳定或与BASE漂移相当；停止，不通过增加重复次数追逐结论。

只有当I75和I50P同时表现出清楚且有序的剂量趋势时，才考虑把确认mini-block扩展为BASE/I75/I50P各6次。该扩展必须在pilot分析后另行冻结，不能现场自行追加。

## 9. 本轮最小工作量

- P04T1V通过后：4次闭合状态、16次sweep；
- 若只授权I75：3次闭合状态、12次sweep；
- pilot效果理想但需装配确认：再增加2次闭合、12次sweep；
- 不执行多个完整ABAB block，不旋转方向，不改变距离，不增加新打印件。
