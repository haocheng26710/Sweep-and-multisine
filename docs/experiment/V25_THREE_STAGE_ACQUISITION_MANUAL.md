# V2.5 三阶段一次性采集执行手册

状态：采集前冻结草案  
日期：2026-08-24  
范围：无挡板；只采集真实测量，不分析数据，不读取既有 final-test

> **采集后偏差记录（2026-08-24）：** 实际 S1 未保留两个独立 block 的推断用途，而按每条件单 campaign 六次处理；实际 S2/S3 为每方向单 campaign 四次。主分析按统一、与结果无关的“距组中位谱最远一次 flag”规则分别采用 5-of-6 与 3-of-4，并保留全部重复的敏感性分析。下文仍原样保留采集前计划，不能用它追溯性声称实际完成了独立 block 验证。详见 `../progress/V25_S1_S2_S3_JOINT_RESULTS.md`。

## 1. 本轮采集目标与总数

本轮一次性收齐三个阶段的数据：

| 阶段 | 内容 | 基础测量数 |
|---|---|---:|
| S1 | P05 直管基线及 HR01–HR08 单入口标定；2 个独立装配 block，每条件连续 3 次 | 54 |
| S2 | 同时段 U4-Symmetric 直管控制；4 个方向 × 3 次 × 2 blocks | 24 |
| S3 | U4-HR 频率编码阵列；4 个方向 × 3 次 × 2 blocks | 24 |
| 合计 | 不含额外故障重测 | **102** |

详细配置、顺序和全部准确文件名在 `V25_THREE_STAGE_ACQUISITION_MATRIX.csv`。任何额外重测均保留原文件，因此实际文件数可以大于 102，但不能少于 102。

## 2. 开始前给零件贴固定身份

- 4 个 P09 实心块：`D01`、`D02`、`D03`、`D04`；始终分别用于 45°、135°、225°、315°。
- 8 个 P05 直管：`S01`–`S08`。主实验始终使用 `S01`–`S04`，其余作为备件；不要在 B02 无记录地换成另一件。
- 8 个 P10 堵塞头：`PL01`–`PL08`。第一阶段固定使用三个状态一致的堵头关闭 90°、180°、270°直管外口。
- HR 模块必须保证 tray、gasket、lid 编号一致，例如 HR03 托盘只能配 HR03 密封垫和 HR03 薄盖。
- 每次装盖前拍一张正上方照片，照片中应能看到装配编号和装置 0°/N 标记。

P09 实心块会填充内外固定通道，不等同于 P10 外口堵头。不要在斜向槽使用“直管 + P10”替代现有四个 P09。

## 3. 所有阶段共同测量设置

为了与既有正式实验和 SUP-1 保持连续性，继续使用原固定条件：

- REW V5.31.3；
- 48 kHz，256k，1 repetition；
- No timing reference；
- Set t=0 at IR peak；
- sweep/export 覆盖 200–8000 Hz；
- -30 dBFS；
- Windows 输出 50；
- iMM-6C 输入 100；
- 麦克风校准文件 `CMM29939.txt`；
- 设备、扬声器、麦克风、房间、距离和音量不变；
- 导出未经 1/12-octave 平滑替代的原始 REW TXT；平滑只在后续分析副本中完成。

方向按“哪个带标签的设备入口正对声源”记录，而不是按转盘旋转正负号猜测：

- `D000`：设备 0°入口正对声源；
- `D090`：设备 90°入口正对声源；
- `D180`：设备 180°入口正对声源；
- `D270`：设备 270°入口正对声源。

第一次 D000 装配完成后拍方向基准照片。P02 的 N 标记必须始终与设备 0°槽一致。

## 4. 两个 block 的含义

每个条件内的 `R01`、`R02`、`R03` 是不移动、不拆装的连续技术重复。

`B02` 不是继续多测三次。进入 B02 前必须：

1. 停止采集并记录时间；
2. 拆下主盖，取出并重新放置该阶段的全部模块、P08B 压力垫和 P09；
3. 重新安装主盖并按相同对角顺序分轮紧固；
4. 将装置从定位位置移开，再放回预先标记的位置；
5. 扬声器和房间基准不动；
6. 拍摄新的 B02 装配照片。

如果无法在同一天完成，可以把 B02 放在第二天；不要取消 B02。记录日期、室温和任何房间变化。

## 5. 推荐实际采集顺序

为减少时间漂移与配置顺序完全重合，按下列顺序完成：

1. S1-B01：P05、HR01、HR02、HR03、HR04、HR05、HR06、HR07、HR08；
2. S2-B01：D000、D090、D180、D270；
3. S3-B01：D000、D090、D180、D270；
4. 完成 B02 独立重新装配/定位；
5. S1-B02：HR08、HR07、HR06、HR05、HR04、HR03、HR02、HR01、P05；
6. S3-B02：D270、D180、D090、D000；
7. S2-B02：D270、D180、D090、D000。

每到一个条件，连续完成 R01、R02、R03 后才改变方向或装配。

## 6. 第一阶段 S1：单入口频率标定

目的：在同一物理入口位置比较 P05 与全部 HR01–HR08，确定实际峰/谷、带宽、重复性和装配漂移。整个 S1 中声源始终正对设备 0°入口，不旋转方向。

### 6.1 固定槽位状态

| 槽位 | S1 状态 |
|---:|---|
| 0° | 当前测试模块：P05-S01 或 HR01–HR08；外口开放，不装 P10 |
| 45° | P09-D01 实心块 |
| 90° | P05-S02 直管，外口装 P10 堵头 |
| 135° | P09-D02 实心块 |
| 180° | P05-S03 直管，外口装 P10 堵头 |
| 225° | P09-D03 实心块 |
| 270° | P05-S04 直管，外口装 P10 堵头 |
| 315° | P09-D04 实心块 |

未测试方向不要安装“HR + P10”。即使外口被堵，HR 内颈仍可能把其腔体作为中心腔的侧支负载。使用直管 + P10 可让所有单模块条件拥有一致的非测试边界。

### 6.2 九个条件

1. P05-S01 直管基线；
2. HR01，目标 1200 Hz；
3. HR02，目标 1500 Hz；
4. HR03，目标 1850 Hz；
5. HR04，目标 2250 Hz；
6. HR05，目标 2700 Hz；
7. HR06，目标 3200 Hz；
8. HR07，目标 3800 Hz；
9. HR08，目标 4500 Hz。

每换一个 0°模块都检查对应 gasket/lid、P08B 压力垫和主盖压紧状态。每个条件在 B01、B02 分别连续测三次。

文件名示例：

- `V25-S1-CAL-B01-P05-D000-R01.txt`
- `V25-S1-CAL-B01-HR01-D000-R01.txt`
- `V25-S1-CAL-B02-HR08-D000-R03.txt`

## 9. 每个条件开始前的十秒检查

- 文件名中的阶段、block、模块/配置、方向和 repeat 是否正确；
- 正对声源的槽位是否与 `Dxxx` 一致；
- S1 只有 0°开放，90°/180°/270°的三个 P10 均完全插入；
- S2/S3 的四个主方向均开放且没有遗留 P10；
- 四个 P09 始终在斜向槽；
- P02 N 标记对准设备 0°；
- 主盖采用相同紧固顺序和力度；
- REW、音量、校准文件和采样设置没有变化；
- 门窗、人员位置和房间状态稳定；
- 当前装配照片已经保存并登记。

## 10. 异常和重测

爆音、扫频被打断、明显环境噪声或错误方向只做 flag，不覆盖原 TXT。

额外重测在原 stem 后增加 `-X01`，例如：

`V25-S3-U4HR-B01-D090-R02-X01.txt`

同时在日志中把原文件标为 `flagged`，把新文件的 `retake_of` 填为原文件名。不要删除“看起来不好”的曲线；后续分析会区分技术事故、真实弱效应和装配漂移。
