# 研究问题与判定标准

协议版本：`rev-001`

冻结日期：2026-08-13

状态：正式 pilot 前冻结；尚未执行压力模拟或真实实验

## 1. 研究范围

本研究比较两种内部声学结构：非对称编码结构 `U4ENC` 与对称基准结构 `U4SYM`。主要实验固定使用单个麦克风，在相同声源、麦克风、几何位置和采集条件下测量四个正交方向：`0°`、`90°`、`180°`、`270°`。

第一阶段以 Sweep 为主要测量方式，用于获得 dense 频谱、建立方向差异和重复误差的主要证据。Multisine 用于快速测量以及与 Sweep 的跨模式验证；在真实 Multisine/P8 获得独立批准前，它不进入真实研究分析。

重复与误差来源必须分开处理：

- `CONT`：不改变装置状态的连续技术重复，用于估计短时采集与仪器重复性；
- `REPOS`：重新定位后的重复，用于估计位置恢复误差；
- `REASM`：重新装配后的重复，用于估计装配变化及结构重建误差。

八方向扩展、V2.5 结构变体和最少 tone 数量只属于探索性研究，不属于本协议的主问题、主假设或主成功门槛。探索性结果不得替代四方向 `U4ENC` 对 `U4SYM` 的确认性判定。

## 2. 主研究问题

在相同声源、麦克风和测量条件下，内部非对称声学结构 `U4ENC` 能否产生可重复的方向相关频谱特征，使四个方向在控制 `CONT`、`REPOS`、`REASM` 以及总体声级差异后仍然可以区分，并且其方向信息量高于 `U4SYM`？

## 3. 假设

- **H0（零假设）**：方向间差异不大于连续重复、重新定位或重新装配误差；`U4ENC` 的方向信息量不优于 `U4SYM`。
- **H1（备择假设）**：`U4ENC` 的方向间差异大于上述误差，并且其方向信息量优于 `U4SYM`。

## 4. 主指标与辅助指标

### 4.1 固定主指标

主指标固定为去均值频谱上的方向增益比：

\[
G_{\mathrm{demeaned}} =
\frac{\operatorname{median}(d_{\mathrm{between\ direction}})}
{\operatorname{median}(d_{\mathrm{within\ direction,\ REPOS}})}
\]

其中：

- 分子是在相同结构和兼容实验条件下，不同方向之间的频谱距离中位数；
- 分母是在相同结构、相同方向下，跨 `REPOS` 的频谱距离中位数；
- 距离必须来自冻结且兼容的 FeatureSet、频带和距离定义；
- 去均值在每个样本内部进行，用于降低总体声级差异对方向形状差异的支配。

在正式 pilot 前允许的唯一 `rev-002` 若涉及距离定义、分析频带或配对规则，必须按第 7 节记录并在看到正式 pilot 结果前冻结。正式 pilot 开始后不得改变这些定义来改善结果。

### 4.2 必须同时报告的指标

- `G_raw`：未进行 sample 内 normalization 的原始频谱方向增益比；
- `G_demeaned`：主指标；
- `G_zscore`：sample 内 z-score 后的方向增益比；
- `REASM` 条件下的同方向变化，包括其距离分布和相对于方向间差异的大小；
- `U4ENC` 与 `U4SYM` 的主指标差值：

\[
\Delta G_{\mathrm{demeaned}} =
G_{\mathrm{demeaned}}(U4ENC) - G_{\mathrm{demeaned}}(U4SYM)
\]

- grouped validation 的 balanced accuracy；
- grouped validation 的 macro-F1。

物理方向差异指标，尤其是 `G_demeaned`、其不确定性以及与 `REASM` 的比较，优先于分类准确率。分类是对方向信息可用性的辅助验证，不能单独推翻物理指标给出的负面结果。

### 4.3 独立性与重复计数

`CONT` 属于技术重复，不能作为独立科学样本数，也不能通过随机拆分到训练集与测试集来增加表观样本量。独立性主要由独立 session、`REPOS` 和 `REASM` 体现。统计摘要、置信区间和分组验证必须保留这些层级；同一批技术重复不得跨越训练/验证边界。

## 5. 判定标准

### 5.1 数据完整性与资格门槛

进入主判定前必须同时满足：

1. 至少 `90%` 的计划样本通过 QC；
2. 不得整组缺失任何一个计划方向或任何一个结构（`U4ENC`/`U4SYM`）；
3. provenance、resolved config、artifact hash 和样本身份全部有效且可审计；
4. 不允许数字削波；不允许无法解释的输入异常进入主分析；
5. QC 的 warning、exclude candidate、unavailable 和人工审核必须保留，不得通过静默删除得到合格数据集。

若上述数据门槛不满足，不得宣称主假设通过。应先按第 6 节判定为“调整后继续”或“重新设计”。

### 5.2 物理方向效应门槛

主结果必须同时审查：

- `G_demeaned(U4ENC) > 1`；
- `G_demeaned(U4ENC) > G_demeaned(U4SYM)`；
- 在 demean 和 z-score 后仍保留方向差异，即结果不能只由总体声级变化解释；
- `U4ENC` 的方向间差异大于 `REASM` 引入的同方向变化；
- 正式 pilot 必须报告 `95%` 置信区间；目标为：
  - `G_demeaned(U4ENC)` 的 `95%` 置信区间下限大于 `1`；
  - `ΔG_demeaned` 的 `95%` 置信区间下限大于 `0`。

点估计满足但置信区间跨越相应边界，只能作为方向正确但证据不足，不能判定主门槛已通过。

### 5.3 分类辅助门槛

- 四方向分类的机会水平为 `25%`；
- 实用目标为 grouped validation balanced accuracy 至少 `50%`；
- 同时报告 macro-F1、每方向表现、有效 prediction coverage 和不确定性；
- 分类必须使用 leave-one-session、leave-one-REPOS、leave-one-REASM 或等价的预先声明分组验证；
- 禁止随机拆分同一批 `CONT` 技术重复，禁止让同一物理状态的重复同时出现在训练和验证中；
- final-test 在独立批准前继续 sealed，不得用于模型、阈值、特征、频带或 tone 选择。

达到分类目标不能弥补 `G_demeaned`、`ΔG_demeaned` 或 `REASM` 比较失败。物理方向差异指标始终优先。

## 6. 三类决策

### 6.1 继续原设计

只有在以下条件全部满足时，才进入正式实验：

- 数据完整性与资格门槛全部通过；
- `G_demeaned(U4ENC) > 1` 且高于 `U4SYM`；
- demean 和 z-score 后方向效应仍存在；
- 方向效应大于 `REASM` 同方向变化；
- 正式 pilot 的两个主要 `95%` 置信区间下限分别高于 `1` 和 `0`；
- grouped classification 达到预先规定的分组验证要求，并作为辅助证据与物理指标方向一致；
- 没有未解决的 provenance、QC、泄漏或 final-test incident。

### 6.2 调整后继续

若指标方向正确但不稳定、置信区间跨越边界、QC 通过率不足但原因明确且可修复、或设备/流程误差仍需降低，则判为“调整后继续”。调整必须针对测量稳定性、样本完整性或预先识别的工程问题；不得根据结果挑选更有利的主指标、阈值、方向、结构、频带或样本。

完成有边界的压力模拟和少量真实设备诊断后，如确需修改协议，只能使用第 7 节规定的唯一 `rev-002` 窗口。调整后必须重新完成相应 pilot 门槛，不能把调整前后不兼容的数据静默合并。

### 6.3 重新设计

出现下列任一实质性情形时，应重新设计，而不是通过分析选择挽救结论：

- normalization 后方向效应消失，表明表观差异主要来自总体声级；
- `U4ENC` 不优于 `U4SYM`；
- `REASM` 引入的同方向变化持续大于方向效应；
- 方向、结构或实验条件存在整组缺失，且无法通过预先计划的补测恢复；
- 持续存在无法解释的削波、输入异常、provenance 或身份问题；
- 需要在正式 pilot 结果出现后改变主问题、主指标或成功阈值才能得到正面结论。

重新设计产生的新结构或新问题必须建立新的协议 revision/研究阶段；不得把它描述为本 `rev-001` 的确认性成功。

## 7. 冻结与修订规则

1. 当前协议冻结为 `rev-001`。
2. 在有边界的压力模拟和少量真实设备诊断完成后、正式 pilot 开始前，最多允许一次 `rev-002`。
3. `rev-002` 必须记录：修改原因、修改人、修改日期、修改前内容、修改后内容和对既有数据兼容性的影响。
4. `rev-002` 不得使用 final-test，也不得依据正式 pilot 或其他目标测试结果反向优化成功门槛。
5. 正式 pilot 开始后，不得根据结果修改主研究问题、`G_demeaned` 主指标或成功阈值。
6. 正式 pilot 开始后新增的分析、方向、结构、频带、分类器或 tone 研究必须明确标记为探索性。
7. final-test 继续保持 `sealed`；除非完成独立批准流程，不得读取或用于任何开发、压力模拟、pilot 或修订。
