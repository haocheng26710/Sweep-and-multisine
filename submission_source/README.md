# Submitted analysis source

This directory contains the nine Python files from the final local supporting
digital-files submission (`suplyment/source_code`, 4 September 2026).
The files are copied without numerical changes. Matching datasets and printed
parts remain in the local submission ZIP and project closeout archive, rather
than being uploaded with the program source.

The numbered scripts correspond to the eight experiments in the dissertation;
`measurement_io.py` provides common measurement input and preprocessing.
Python dependencies are NumPy, SciPy and scikit-learn. The submission source is
not a replacement for the original simulation scripts elsewhere in this repo.
